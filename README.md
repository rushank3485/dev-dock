# ⚡ DevDock · Developer Utility Suite

> An integrated, offline-first client-side utility cockpit for engineers: JSON studio, JWT inspection, Base64 encoding, and cryptographic helpers.

## ⚡ Tooling Capabilities

- **JSON Studio:** High-speed syntax beautifier, one-click minifier, and lint error pinpointing.
- **JWT Inspector:** Zero-network-call client parsing for Header and Payload claims with algorithm decoding.
- **Base64 & URL Transformer:** UTF-8 compliant bidirectional string conversions.
- **Offline-First Privacy:** All conversions execute entirely within the browser context; zero data is dispatched to external servers.
